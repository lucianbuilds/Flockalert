# README Images

Put the optional project photos in this folder with these names:

- `device-build.jpg` - completed device
- `wiring.jpg` - wiring and hardware connections
- `config-page.png` - Wi-Fi configuration page

The image markup is intentionally commented out in the root README until the files are added, so the public README will not show broken-image icons. Once the images are in place, remove the matching HTML comment markers in `README.md`.
